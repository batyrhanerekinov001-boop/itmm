# ITMM лендинг (React + Vite + Express)

## Быстрый старт
1. Установите Node.js LTS (желательно 18+).
2. Создайте файл `.env` по образцу `.env.example` и заполните:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. Установите зависимости:

```bash
npm install
```

4. Запустите фронт + API:

```bash
npm run dev
```

Фронтенд откроется на `http://localhost:5173`, API слушает `http://localhost:3001`.

## Продакшн

```bash
npm run build
npm start
```
